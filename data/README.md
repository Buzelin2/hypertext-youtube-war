# Data Directory

Place raw YouTube comment exports here when running the training scripts.

The example configs expect files under:

- `data/raw/iran_videos_with_all_comments_sample100.json`
- `data/raw/iran_news_with_all_comments_sample100.json`
- `data/raw/afgh_channels_with_all_comments_sample100.json`
- `data/raw/afgh_news_with_all_comments_sample100.json`

Raw data is intentionally not tracked in git.
